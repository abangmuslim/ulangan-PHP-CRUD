Cara menjalankan
1. Simpan kode sebagai buatuser.php di folder utama proyek.
2. Pastikan database rumahsakitahmadi5 sudah dibuat dan tabel user, pasien, serta dokter memiliki kolom sesuai skema.
3. Jalankan melalui browser menggunakan alamat lokal proyek, misalnya http://localhost/2026/5ULANGANKOMPETENSI/MODEL5/buatuser.php.
4. Periksa hasil setiap akun yang ditampilkan.
5. Setelah selesai, hapus buatuser.php agar orang lain tidak dapat mencoba membuat akun melalui file tersebut.
